## 📌 Overview
A two-stage machine learning framework to predict cervical cancer risk 
using the UCI Cervical Cancer Risk Factors dataset. The model classifies 
patients as **High Risk** or **Low Risk** based on clinical parameters.

## 📊 Dataset
- **Source:** UCI Machine Learning Repository
- **Features:** 36 clinical risk factors including age, smoking habits, 
  STD history, and hormonal contraceptive use
- **Target:** Biopsy result (Cancer / No Cancer)

## ⚙️ Methodology
- ✅ Missing value handling (replaced with median)
- ✅ Correlation-based feature selection
- ✅ Logistic Regression model — binary classification
- ✅ Patients classified as **High Risk** or **Low Risk**
- ✅ Built a UI to demonstrate end-to-end workflow
